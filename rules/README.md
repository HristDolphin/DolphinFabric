# SafeGate 规则集

本目录存放安全闸门（SafeGate）的**哈希规则集**：顶部选择在线模式时，命中违规特征的
设定条目的注入等同关闭（优先于常驻/逻辑/向量模式，不修改词条原设置），安全条目放行。

## 目录结构（按来源分三类）

```
rules/
├─ official/    # 官方：随仓库发布的内置种子（公开法律文本术语生成）
├─ community/   # 社区：PR 提交的哈希集（仓库只收哈希，明文永不入库）
└─ user/        # 用户：本地构建（.gitignore 忽略，不进仓库）
```

**加载优先级**：`official` → `community` → `user`（用户最高，同哈希词条后者覆盖前者）。

## 为什么不放明文词库

仓库中**不包含任何敏感词明文**，只有 `blake2b-64bit` 哈希（16 位十六进制）。
匹配方式：正文归一化后做 2~8 字滑动窗口 n-gram，逐窗口哈希查集合。

- 哈希不可反向读出词条，仓库不构成"违规文本分发"
- 哈希可被离线暴力枚举还原（低熵短串），因此它只防"分发/误泄露"，不是密码学保护
- 明文词库由使用者**本地**构建（见下），永不入库

## 文件格式

```json
{ "cat": "gamble", "label": "赌博", "buckets": { "2": ["hex..."], "3": [...] } }
```

- `buckets` 的 key 为词长（归一化后的字符数），value 为该长度词的哈希集合
- 运行时只对存在桶的长度做滑窗，未命中长度的窗口直接跳过（提速）

## 如何构建/扩充词库（明文只在本地）

```bash
# 默认输出到 rules/user/（用户本地，不提交）
python tools/build_dict.py 我的词表.txt gamble 赌博
# 显式指定输出位置
python tools/build_dict.py 我的词表.txt gamble 赌博 --out rules/user/gamble.hash.json
# 给社区 PR 用：--out rules/community/<cat>.hash.json
```

1. 词表文件每行一个词，`#` 开头为注释
2. 构建脚本与运行时使用**同一套归一化**（NFKC → 小写 → 去空白/标点/下划线）
3. 生成后按目录语义放置；`user/` 已在 .gitignore，词表明文文件切勿提交

## 官方种子词库来源

`official/` 种子仅收录公开法律法规文本中的标准术语（《网络信息内容生态治理规定》第六条、《刑法》相关罪名、《禁毒法》等），用于开箱即用的演示与基础拦截。
第三方下载的开源词库一律放 `community/`（见 community/README.md），不混入官方库。
更完整的词库请使用者依据自身合规需求本地构建，或通过社区贡献。
